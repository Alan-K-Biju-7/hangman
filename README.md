# Nightfall

A cinematic, dependency-free Hangman game. Open `index.html` in a modern browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

Features include three difficulties, physical-keyboard and touch input, hints, procedural rain, reactive sound, animations, streaks, credits, win-rate tracking, and persistent local stats.
